# Crossing Minds

> Crossing Minds is an AI personalization and recommendation company. Its B2B
> Recommendation API delivers profile-to-items, session-to-items and
> item-to-items recommendations from user ratings and interactions, with JWT
> authentication and multi-database, multi-tenant accounts. First-party SDKs
> ship for Python, Node.js, .NET, Java, Ruby, PHP and browser JavaScript. The
> team joined OpenAI; the API, docs, SDKs and status page remain online.

## APIs
- [Crossing Minds Recommendation API docs](https://docs.api.crossingminds.com/): B2B universal recommendation API (v1.0.0), JWT auth
- [Endpoint reference](https://docs.api.crossingminds.com/endpoints/index.html): databases, users, items, ratings, interactions, recommendations, scenarios, background tasks
- [Authentication](https://docs.api.crossingminds.com/authentication.html): JWT bearer + refresh token, individual/service/SAML login
- [Error handling](https://docs.api.crossingminds.com/errors.html): custom error_code/error_name envelope
